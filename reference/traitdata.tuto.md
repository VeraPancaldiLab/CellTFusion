# Clinical data

Data frame with the clinical data across samples

## Usage

``` r
traitdata.tuto
```

## Format

Matrix with samples as rows and traits as columns

## Source

Mariathasan et al. (2018), doi: https://doi.org/10.1038/nature25501

## Examples

``` r
data(traitdata.tuto)
head(traitdata.tuto)
#>                 Best.Confirmed.Overall.Response binaryResponse Enrollment.IC
```
