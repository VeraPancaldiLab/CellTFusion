# Prepare CellTFusion folds for cross-validation with training and test data

This function prepares data for k-fold cross-validation using the
CellTFusion framework. It supports two modes of operation:

1.  If a set of tuned hyperparameters is provided via `bestune`, the
    function will process the full dataset once with those parameters
    and return a single processed training set.

2.  If no tuned parameters are provided, the function will construct
    fold-specific training and test datasets, expanding over a grid of
    CellTFusion hyperparameters and returning them for subsequent model
    training and hyperparameter selection.

## Usage

``` r
prepare_CellTFusion_folds(
  data,
  folds = NULL,
  deconv = NULL,
  universe = NULL,
  paths = NULL,
  normalized = FALSE,
  coldata,
  time_var = NULL,
  event_var = NULL,
  corr_type = "spearman",
  ncores = NULL,
  batch = F,
  batch_id = NULL,
  min_targets_size,
  minMod,
  corr_mod,
  corr,
  high_corr_groups,
  bestune = NULL
)
```

## Arguments

- data:

  A data frame containing gene expression data (samples x genes) and a
  column named `target` indicating class labels.

- folds:

  A list of integer vectors indicating row indices for the training set
  in each fold. The test set is implicitly defined as the complement.

- deconv:

  A matrix or data frame of deconvolution features (samples x features).
  If `NULL`, CellTFusion will run without these features.

- universe:

  Optional universe of features for CellTFusion.

- paths:

  Optional list of prior knowledge resources for CellTFusion.

- normalized:

  Logical. Whether the gene expression data is already normalized.
  Defaults to `FALSE`.

- coldata:

  A data frame with metadata (e.g., sample annotations), must match the
  number and order of samples in `data`.

- time_var:

  Optional numeric vector with survival/censoring time values.

- event_var:

  Optional vector with event labels used for survival tasks.

- corr_type:

  Correlation type passed to CellTFusion. Default is `"spearman"`.

- ncores:

  Integer. Number of CPU cores to use for parallelization. If `NULL`,
  `parallel::detectCores() - 2` is used.

- batch:

  Logical; whether batch correction should be used. Default is `FALSE`.

- batch_id:

  Optional vector of batch identifiers, aligned with samples.

- min_targets_size:

  Hyperparameters for CellTFusion

- minMod:

  Hyperparameters for CellTFusion

- corr_mod:

  Hyperparameters for CellTFusion

- corr:

  Hyperparameters for CellTFusion

- high_corr_groups:

  Hyperparameters for CellTFusion. These can be provided as vectors to
  define a tuning grid when `bestune = NULL`.

- bestune:

  Optional. A data frame of tuned hyperparameters. If provided, the
  function skips fold construction and directly processes the full
  dataset using these values.

## Value

A list with two possible structures depending on `bestune`:

- If `bestune` is provided:

  - `train_cell_data_final`: Final processed cell group feature matrix
    for the full dataset, including the `target` column.

  - `custom_output`: The full CellTFusion object from training.

  - `best_celltfusion_params`: The tuned hyperparameters used.

- If `bestune` is `NULL`:

  - `processed_folds`: A list of folds. Each fold contains:

    - `train_data`: Processed training data with cell group features and
      `target`.

    - `test_data`: Projected test data in the learned feature space.

    - `obs_test`: True class labels for the test set.

    - `rowIndex`: Row indices corresponding to the test samples.

    - `fold_name`: Fold identifier (if provided).

    - `params`: Hyperparameter values used for this fold.

## Details

For each fold, training and test sets are generated by running the
[`CellTFusion()`](https://verapancaldilab.github.io/CellTFusion/reference/CellTFusion.md)
pipeline on the training data (gene expression and optional
deconvolution features). The trained projection is then applied to the
test data to ensure comparability between folds.

When `bestune = NULL`, the function expands all possible hyperparameter
combinations via
[`expand.grid()`](https://rdrr.io/r/base/expand.grid.html) and runs
CellTFusion separately for each fold and parameter set. This can be
computationally expensive, so the function supports parallelization via
foreach, doParallel, and parallel.

The results of this function are designed to be passed directly to
`compute_custom_k_fold_CV()` for hyperparameter selection and model
evaluation.
